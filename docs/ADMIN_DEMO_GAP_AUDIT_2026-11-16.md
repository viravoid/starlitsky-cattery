## 已明确取消或替代

- 猫舍介绍页不恢复旧 Demo 顶部主图轮播。预览沿用当前小程序名片、主理人和正文布局。
- Demo 的喂养文章管理不属于当前项目范围；现后台维护固定页面内容。
- Demo 假登录和内存数据已由服务端认证、API 和数据库替代。

## 剩余优先级

- P0：本轮静态审计及隔离测试未发现已证实的 P0；这不代表生产环境完成了全量验收。
- P1：本轮确认的固定页面保存前预览已补齐。暂无另一个有充分证据的 P1 缺口。
- P2：概览“待处理事项”中的评论总数并非待审数，可在后续概览文案/指标调整时处理。
- 验收缺口：猫咪和窝次全字段、问卷审核、社区管理、家长生命周期及媒体库更多操作需要专项隔离浏览器验收，当前属于“代码已实现但缺本轮实际验收”，不能标记全部可用。

## 环境边界

本轮只向隔离 SQLite、API 和浏览器写入测试数据。`https://api.starlitskycattery.top/health` 与 `https://admin.starlitskycattery.top/` 在本轮只读检查均返回 HTTP 200，但端点未提供部署 SHA，因此生产 API 和后台的准确代码版本未知。没有读取微信控制台中的体验版或正式版版本信息；既有上传记录不能证明正式发布。
