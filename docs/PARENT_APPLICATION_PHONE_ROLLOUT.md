# 家长申请与微信手机号上线核对

代码中的家长申请不依赖手机号授权。微信登录识别用户，申请人的手机号或微信号用于联系，只有后台审核通过才授予家长权限。微信手机号接口失败时可直接手动填写联系方式。

## 微信公众平台待核实

本仓库只能确认小程序 AppID 配置为 `wx6d3a94b9d6eadeaa`，无法从代码判断该账号的主体资格、功能开通状态、当前额度及隐私指引是否已审核。负责人应登录该 AppID 对应的[微信公众平台](https://mp.weixin.qq.com/)，逐项检查：

1. **设置 → 基本设置 / 小程序信息**：主体不是个人，已完成微信认证，账号具备手机号能力。实际入口名称以平台当前页面为准。
2. **管理 → 付费管理 → 手机号快速验证组件**：确认能力可用、剩余额度、当前套餐、成功调用的实际计费规则及是否需要购买。不要因本次代码改动自动购买或充值。
3. **设置 → 用户隐私保护指引**：确认已声明获取手机号，说明用途为联系及核实家长申请，且指引状态允许体验版使用。
4. **开发管理 → 开发设置**：确认体验版使用的 AppID、服务器域名和当前后端环境；在微信开发者工具及真机上使用支持 `getPhoneNumber` 临时 code 的基础库（至少 2.21.2）。

接口采用[微信小程序获取手机号能力](https://developers.weixin.qq.com/miniprogram/dev/framework/open-ability/getPhoneNumber.html)的用户点击 `getPhoneNumber` → 临时 code → 服务端 `getuserphonenumber` 流程。代码没有调用真实手机号接口进行测试，测试响应均为模拟数据。平台资格和费用需要以该账号的公众平台实时显示为准。

## 体验版验收

1. 无手机号直接微信登录并使用普通功能。
2. 拒绝手机号授权，使用手动手机号或微信号提交家长申请。
3. 在能力、隐私指引及额度均确认后，使用已获授权的测试人员真机点击微信手机号按钮；确认后台标注为“微信获取的手机号”，但申请仍待审核。
4. 后台分别拒绝和通过测试申请，确认角色和猫咪归属只在通过后出现。

不得在此核对过程中修改生产 SQLite、部署或重启生产 API、购买额度或发布正式小程序。
